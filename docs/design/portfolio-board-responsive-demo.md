# 组合看板自适应布局

状态：Demo 已获用户确认，正式组件已实现。

预览：[portfolio-board-responsive-demo.html](../../output/portfolio-board-responsive-demo.html)。可直接用浏览器打开，无外部依赖，使用演示数据。

## 问题与方案

此前 `GridPortfolioBoard` 根据视口宽度在 768 / 1280 / 1536px 切换到 2 / 3 / 4 列。外层通用布局和网格页容器均有内边距，实际看板宽度更小；卡片标题、代码、编辑按钮和持仓标签又挤在同一行。

正式实现沿用现有颜色、字段及数字字号，按实际容器宽度自动排布卡片，目标最小卡宽 380px，小于此宽度时单列铺满。卡片头部允许换行并保留上下 16px 留白，保留完整名称和持仓标签；备注仍截断并提供完整提示。汇总区默认 2 列，容器达到 600 / 900px 时切换为 3 / 5 列；440px 以下筛选控件允许伸缩换行并收窄卡片内边距，280px 以下报价区纵向排列。

布局位于 `src/components/grid/grid-portfolio-board.tsx`，样式位于 `src/app/view/grid/grid.css`。容器查询使用命名容器 `portfolio-board`，卡片覆盖限定在 `.grid-portfolio-board` 内，点位跟踪页复用卡片保留原样式；行情查询、金额计算、排序、搜索和操作回调沿用原逻辑。

## 交互与边界

- 可搜索名称和代码、切换排序、切换原列数与标题布局对照。
- 计算器、流水、编辑及页面操作只显示预览反馈，不连接账户、交易或行情。
- 对照仅复现现有列数断点和标题不换行约束，不是完整生产页面截图。
- 正式实现仅限组合看板；`GridPortfolioCard` 还被点位跟踪页复用，已用看板作用域限制样式影响。
- Demo 仅用于布局对照；正式组件另行验证。
