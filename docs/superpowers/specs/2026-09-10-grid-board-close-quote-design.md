# 组合看板卡片：收盘价与下一买/卖

> 日期：2026-09-10  
> Demo：`output/grid-portfolio-card-close-demo.html`

## 数据

- 收盘：共享表 `etf_daily` 该标的最新 `trade_date` 的 `close`（只读）。标的取策略 `symbol` 开头 6 位数字，对不上池内代码则无行情。
- 档位：当前保存快照 `legs` + 该策略流水；是否未买/待卖与结果表执行列相同（`awaitingSell` = 上一笔是买）。

## 对比

- **下一买**：未买档（`!awaitingSell`）里，买入价离收盘绝对值最近的一档计划买价。
- **下一卖**：待卖档里，最后一笔买入 `createdAt` 最新的那档计划卖价；没有买入时间则取待卖档中买入价最低的一档。
- 收盘高于锚定价：再跌 `(收盘 − 锚定价) / 收盘`；低于：再涨 `(锚定价 − 收盘) / 收盘`；相等：已到位。无行情或缺档：`—`。

## UI

卡片备注下三块：收盘（含日期 MM-DD）、下一买、下一卖；其下仍为预计最大亏损 / 已投入金额 / 已实现收益。
