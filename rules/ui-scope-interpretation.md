# UI 范围识别规则

- 用户说“某卡片里面的页面”“点击卡片后的页面”时，默认指卡片跳转后的目标页面，而不是卡片组件本身。
- 动手前必须追踪卡片的 `href`、`onAction` 或 `router.push`，明确实际目标路由，并复述“修改范围 / 不修改范围”。
- 如果用户明确允许保留已经完成的卡片改动，后续只追加目标页面改动，不回滚已获认可的内容。

## 配色与模块分组

- 用户提供色板不等于要求把所有强调色同时铺进页面；优先保留统一主色，扩展多色前先判断是否确有业务区分需要。
- 当前点位聚焦 Demo 的配色回退到统一靛蓝曲线、蓝灰文字和小面积语义色。用户已否定按指数、ETF、基金、原文分别配多种强调色的版本，后续不要自行恢复。
- 用户要求分割线克制时，优先用浅色背景和留白区分模块；收掉装饰性横线、竖线和卡片描边，保留图表数据线、必要操作状态及键盘焦点。
